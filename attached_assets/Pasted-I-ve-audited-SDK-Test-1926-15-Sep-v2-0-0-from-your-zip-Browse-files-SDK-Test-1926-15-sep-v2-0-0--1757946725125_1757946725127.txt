Production blockers (still)

Secret zeroization not implemented
No evidence of portable memory scrubbing (OPENSSL_cleanse, explicit_bzero, memset_s, or sodium_memzero).
➤ Add a secure_zero() helper and use it for keys/IVs/tags and temporary buffers on success and error.

Typed JS/TS error classes missing
Couldn’t find AuthTagError / InvalidInputError (or equivalents).
➤ Public API should throw only these types for: bad auth tag, invalid inputs, KID mismatches.

C packaging incomplete
CMakeLists.txt needs install() rules and a pkg-config file (sdkcrypto.pc) so downstreams can pkg-config --cflags --libs sdkcrypto.
➤ Add install for headers and lib, and generate the .pc.

Security governance docs incomplete
No SECURITY.md and/or Threat Model doc.
➤ Add coordinated disclosure policy (contact, supported versions) and a short STRIDE-style threat model.
